# My Codex Skills

这个仓库用于保存个人 Codex 技能。

## 已收录技能

### `cn-invention-patent-drafting`

用于从算法、技术思路、工作流程、科研成果或工程技术披露出发，撰写、审查和修订中国发明专利材料，覆盖：

- 权利要求书、说明书和摘要；
- 概念阶段发明的技术链重建与充分公开检查；
- 技术事实状态、证据编号及权利要求支持矩阵；
- 现有技术检索与八轮迭代审查；
- 正式交付前的独立 Agent 对抗审查；
- 黑白专利附图与附图标记一致性；
- 代理机构 DOCX 模板交付；
- 算法、软件、AI、控制、工程流程等通用技术披露；
- 专利文档的确定性自动审查。

## 安装

将技能目录复制到 Codex 的个人技能目录：

```bash
cp -R cn-invention-patent-drafting ~/.codex/skills/
```

重新启动或刷新 Codex 后，即可通过 `$cn-invention-patent-drafting` 使用。

## 说明

本技能用于辅助技术材料整理和专利文本质量控制，不能替代持证专利代理师的法律判断，也不承诺专利授权结果。
