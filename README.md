# My Codex Skills

这个仓库用于保存个人 Codex 技能。

## 已收录技能

### `cn-invention-patent-drafting`

用于从技术披露出发，撰写、审查和修订中国发明专利材料，覆盖：

- 权利要求书、说明书和摘要；
- 现有技术检索与八轮迭代审查；
- 黑白专利附图与附图标记一致性；
- 代理机构 DOCX 模板交付；
- CAE、工程软件、AI 辅助工程及多体动力学技术披露；
- 专利文档的确定性自动审查。

## 安装

将技能目录复制到 Codex 的个人技能目录：

```bash
cp -R cn-invention-patent-drafting ~/.codex/skills/
```

重新启动或刷新 Codex 后，即可通过 `$cn-invention-patent-drafting` 使用。

## 说明

本技能用于辅助技术材料整理和专利文本质量控制，不能替代持证专利代理师的法律判断，也不承诺专利授权结果。
